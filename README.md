# Weaving Voice

Static single-page site for Weaving Voice — Cultural & Music Education Trust.

## Files
- `index.html` — the site
- `assets/` — images
- `netlify.toml` — Netlify config (no build step, publish from repo root)

## Deploy
Push to GitHub → connect the repo on Netlify → accept the defaults. No build command, publish directory is `.`.

## Local preview
Open `index.html` in a browser, or run any static server in this folder:
```
python3 -m http.server 8000
```
